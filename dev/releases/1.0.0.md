  <h3>Kinal — v1.0.0 · The First Self-Hosted Release</h3>
</div>

---

**Kinal now compiles itself.** Kinal 1.0.0 is the first release to ship a compiler written in Kinal and built by Kinal. The command is `kinal.exe` on Windows and `kinal` on Linux and macOS.

We started with the 0.10.0 C compiler to build the new compiler from source, then used the new compiler to rebuild itself twice. On Windows, Linux and macOS, on both x64 and Arm64, the last two builds produced byte-for-byte identical compiler executables. Each SDK ships the final build, which passed 107 regression test groups on its host. [Build and test results](https://github.com/Kinal-Lang/Kinal/actions/runs/45049460402)

## Compiler and runtime

- The same command builds native executables and KNC programs. The SDK includes KinalVM, the standard packages, linker support and the language server.
- Native code generation improves direct scalar calls, short-lived values, fixed arrays and GC root tracking. The KNC backend indexes reachable functions and globals and grows its bytecode buffers on demand.
- `IO.Kinal.VM.Executor` is an optional package for embedding the compiler and VM in a Native application. Compile a source string, pass its KNC bytes to another object, or load an image from disk. Programs that omit the import can ship independently of the module.
- KinalVM 0.9.0 accepts KNC2 revisions 2, 3 and 4. Revision 4 records the producer version so a loading or execution error can identify a compiler mismatch.

## Upgrading

Extract the entire archive for your host. Keep `llvm`, `linker`, `runtime` and `stdpkg` next to the compiler. On Linux and macOS, install LLVM 21 for native linking. On macOS, freestanding ELF builds also use Homebrew’s `lld@21`. Run `kinal --version` and `kinalvm --version` to inspect the installed components. Verify archives using `SHA256SUMS.txt`.
