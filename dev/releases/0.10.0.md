**0.10.0 is the final feature release of the compiler implemented in C.** The 0.10 line remains available for maintenance fixes and as a bootstrap seed. Compiler development and future feature releases move to the compiler written in Kinal.

## What's new

- KinalVM 0.9.0 reads KNC2 revisions 2, 3 and 4. New bytecode records its producing compiler version. A compatible program built with a different compiler still runs. If loading or execution fails, the diagnostic includes both versions.
- Native applications can import the optional `IO.Kinal.VM.Executor` package to compile Kinal source at runtime, retrieve the bytecode as a byte array, or execute an image obtained from memory or disk.
- The Windows desktop UI package adds a Direct3D 11 drawing surface, layout, input events and custom controls.
- `IO.Text.Builder` supports incremental string construction. File append and first-line reads avoid loading the entire file. The runtime and VM also improve collection storage reuse and release references when elements are removed.
- The repository now includes reproducible benchmarks for generated code, compiler throughput and runtime memory behavior.

Windows, Linux and macOS packages are provided for x64 and Arm64. Verify a download against `SHA256SUMS.txt`.
